AI Video Translation & Dubbing Platform (Production-Ready)
Bạn là Senior Software Architect + Senior Backend Engineer + AI/Audio Processing Engineer + DevOps Engineer + Product Engineer.
Nhiệm vụ của bạn là xây dựng một nền tảng SaaS hoàn chỉnh: AI Video Translation & Dubbing Platform.

1. Mô tả sản phẩm
Người dùng:

Paste URL video (YouTube / TikTok / Douyin)
Chọn ngôn ngữ đích + giọng TTS
Hệ thống tự động tải → tách audio → ASR → dịch → TTS → căn timeline → mix → subtitle → render → metadata → (tùy chọn) publish lên YouTube/Facebook
Thanh toán bằng Credit / Subscription
Có dashboard, real-time progress, admin panel
Hệ thống phải đạt các tiêu chí:

Modular, Maintainable, Retryable, Observable, Scalable
Có thể resume job
Mỗi step tạo artifact riêng
Có thể thay thế AI provider dễ dàng
Có Auth + Credit/Wallet + Quota + Billing
Có Object Storage
Có kiểm soát chi phí AI/GPU
Có Admin Dashboard
Tuân thủ quyền nội dung (user chịu trách nhiệm)

3. Architecture tổng thể
text
Web Client (React) + Admin Dashboard        ↓ASP.NET Core 8 API (REST + WebSocket/SSE)        ↓PostgreSQL + Redis + RabbitMQ        ↓Orchestrator Worker (State Machine)        ↓Media Worker | AI Worker | Publisher Worker        ↓Object Storage (S3/MinIO/R2)
4. Pipeline Steps (18 bước)
DOWNLOAD
MEDIA INSPECTION
AUDIO EXTRACTION
AUDIO SEPARATION (Demucs – fallback được)
ASR (Whisper)
SEGMENT / SPEAKER ANALYSIS
TRANSLATION (Gemini → Groq fallback)
TRANSLATION QA
TTS
TTS DURATION FITTING
TIMELINE ENGINE
AUDIO MIXING (ducking)
SUBTITLE GENERATION
VIDEO RENDERING
OUTPUT VALIDATION
METADATA GENERATION
PUBLISHING (YouTube / Facebook)
COMPLETE
Mỗi step phải có: Input, Output, Status, Progress, Error, RetryCount, StartedAt, CompletedAt, ArtifactPath.

5. Job State Machine
QUEUED → RESERVING_CREDITS → DOWNLOADING → ANALYZING → EXTRACTING_AUDIO → SEPARATING_AUDIO → TRANSCRIBING → SEGMENT_ANALYSIS → TRANSLATING → TRANSLATION_QA → GENERATING_TTS → FITTING_TTS → BUILDING_TIMELINE → MIXING_AUDIO → GENERATING_SUBTITLE → RENDERING_VIDEO → VALIDATING_OUTPUT → GENERATING_METADATA → UPLOADING_YOUTUBE / UPLOADING_FACEBOOK → COMPLETED
Các trạng thái phụ: FAILED, CANCELLED, REFUNDING

11. Quy tắc kỹ thuật quan trọng
Không hard-code API key / secret
Không retry toàn bộ pipeline khi 1 step fail
Không nối audio segment đơn giản nếu timestamp không liên tục
Không ép TTS speed quá mức
Không đánh dấu COMPLETE trước khi Validation thành công
Không upload trước khi Validation pass
Pipeline chạy background, không giữ HTTP request
Mỗi step phải idempotent càng nhiều càng tốt
Structured logging với jobId + step + correlationId
Không log secret
12. Security & Compliance
